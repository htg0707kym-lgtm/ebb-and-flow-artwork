# 鑑賞ページの元コード
ここは公開中の鑑賞ページのソースです。ブラウザ上でファイル名を押すとコードを読めます。
制作アプリ全体ではなく、公開プレーヤーに必要なコードだけを収録しています。
ボーカル単体・個別ステム・制作PCのAPI・秘密設定は含みません。
## どこを読む？
| ファイル | 内容 |
| --- | --- |
| `watch.jsx` | 完成動画／リアルタイムの切替、スライダー |
| `watch-realtime.jsx` | リアルタイム再生と公開データの読込み |
| `Film.jsx` | 映像の合成・レイヤー・楽器反応 |
| `partition-shader.mjs` | 境界やにじみなどの描画 |
| `viewer-controls.mjs` | 流速・うねり・残像の制御 |
| `use-lyric-textures.jsx` | 歌詞の表示 |
| `share.html` / `share.mjs` | 投稿用素材ページ |
元の制作フォルダとは違い、読みやすいよう鑑賞用コードをこのフォルダにまとめています。
公開中の配信は別の固定済みビルドを使います。ここを編集しても自動でサイトへは反映されません。
## 手元で動かす場合（開発者向け）
Node.jsを用意し、このフォルダで `npm install` を実行します。
依存パッケージにはそれぞれのライセンスが適用されます。Remotionの利用条件も確認してください。
画像・音声・設定はコードに同梱していません。リポジトリ先頭の「配信データ」案内に従い、
ベースZIPと2つの更新ZIPを順に展開した公開データを `public/` に置いてください。
その後 `npm run dev` で表示されるローカルURLの `/watch.html` を開きます。
`npm run build` は `dist/watch.html` と `dist/share.html` を生成します。
このコードの公開だけをもって、楽曲・歌詞・音声・画像・第三者ライブラリの
自由な再配布や商用利用を許諾するものではありません。
