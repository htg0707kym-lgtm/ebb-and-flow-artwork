# ebb and flow
[鑑賞ページへ](https://htg0707kym-lgtm.github.io/ebb-and-flow-artwork/)
## 深海描画基盤 ENA / 海洋魔術技術白書
**海神庁・感情流体演算室／査読：満潮待ち**
本システムは、海底側で演算された「まだ言えなかったこと」を、陸側のブラウザへ浮上させる感情流体レンダラーです。一般的なGPUは使用していません。正確には使用していますが、その内部を海として扱うことに、海側の担当者が同意しています。
### 1. エナ互換実行環境
すべての画素は、海神様から貸与された仮想エナに包まれた状態で実行されます。これにより、通常は陸上で失われるはずの青色呼吸が維持されます。
エナが乾くと映像が止まります。これは不具合ではなく、実行環境が陸に憧れた状態です。
### 2. 海と陸の二層アーキテクチャ
| 層 | 実装方式 | 主な責務 |
| --- | --- | --- |
| 海底層 | 非同期しおさい演算 | 言葉になる前の感情を沈めておく |
| 境界層 | 半透過エナ・ブリッジ | 触れたところだけ少し揺らぐ |
| 陸上層 | 思い出の遅延展開 | もう過ぎた歌詞を、違う時間に返す |
海と陸の時刻は同期しません。ただし、音源の再生時刻だけは経理上の都合により同期します。
### 3. ぬくみ雪キャッシュ
使い終わった光は破棄せず、ぬくみ雪として蓄積します。青い画面で生じた未練がキャッシュラインを満たすと、終盤に向かって白が増えます。
キャッシュヒット率は「どれくらい覚えていたかったか」で変動します。忘れたはずの文字が映り込むのは、この機構の正常動作です。
### 4. 冬眠型ガベージコレクション
回収しきれない残像は、いったん眠らせます。時間が経ってから再び浮上しますが、元と同じ場所には戻りません。
実装者も一部の残像がどこで眠っているのか把握していません。起こすと曲が終わるためです。
### 5. 鑑賞者による潮流制御
- **流速**：音楽の時間を動かさず、海だけを急がせる。
- **うねり**：画面の内側に、もう一つの潮を通す。
- **残像**：今の海へ、少し前の海を混ぜる。
- **元に戻す**：観測によって発生した波を、制作時の海へ返す。
スライダーはブラウザから海神庁へ直接つながっています。通信量は祈りの圧縮率に依存します。
### 推奨環境
- 海への接続：必須
- 塩分濃度：気持ち程度
- 満潮時メモリ：十分
- 干潮時メモリ：だいたい思い出
- 最適化方針：重い感情は先に沈める
